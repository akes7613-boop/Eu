BIRTHDAY SURPRISE WEBSITE
========================

A responsive birthday website themed with:
  Espresso: #3A2418
  Warm tan: #A88462

INCLUDED
--------
- Countdown to December 2 (automatically chooses the next upcoming December 2)
- Three uploaded photos in the Our Memory Lane gallery
- Cute CSS-drawn birthday doll and teddy bear decorations
- Birthday letter section
- Interactive cake with three candles
- Tap candles / tap "Blow out the candles" to extinguish them
- Optional microphone blow detection (requires HTTPS or localhost and microphone permission)
- Cake-cutting interaction and confetti
- Mobile responsive layout

HOW TO RUN ON WINDOWS
---------------------
1. Extract the ZIP file.
2. Open the birthday-surprise folder.
3. Double-click index.html to open it in Chrome or Edge.
4. For microphone support, run it through localhost or an HTTPS host. The tap-to-blow option works without a microphone.

OPTIONAL PERSONALISATION
------------------------
- Open index.html and change "my favourite human" / "my sweetest girl" wording.
- Open script.js to change the birthday message variable if you want to use her name.
- Replace photos inside assets/photos while keeping the same filenames, or update the image paths in index.html.
- Change the letter text directly in index.html.

NOTE
----
The date is set to December 2. The countdown automatically targets the next upcoming December 2 based on the visitor's device date.
